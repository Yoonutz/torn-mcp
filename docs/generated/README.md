# docs/generated/

This directory contains **machine-generated** documentation. Do not edit these files by hand — they will be overwritten on the next run.

| File | Generated by | When |
|------|-------------|------|
| `openapi-changelog.md` | `scripts/sync-openapi.mjs` | Weekly (CI) or `npm run sync-openapi` |

## Regenerating

Run `npm run sync-openapi` to refresh all files in this directory from the current `openapi.json`.

To regenerate the TypeScript catalog and README tool table instead, run `npm run regenerate`.
